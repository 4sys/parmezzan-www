## Jak utworzyć menu

Otwórz Terminal i wykonaj:

```bash
cd scripts/TemplateBuilder && node build.js
```

Skrypt utworzy menu w wersji polskiej, angielskiej i włoskiej.

## Jak przekonwertować zdjęcia

Otwórz Terminal i wykonaj:

```bash
cd scripts && .\image-convert.ps1
```

Skrypt przekonwertuje pliki w folderze `assets/resources/convert` .jpg na .webp
